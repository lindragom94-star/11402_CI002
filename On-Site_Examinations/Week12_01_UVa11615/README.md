定義一個funtion f(int n,int a,int b)，此函式專門來找(a在第幾層、b在第幾層、總共要移除多少個點)。funtion裡的邏輯步驟是，c拿來算2的次方，從1次方開始跑，如果(c-1)>=a，就代表數字a是在那一層並把層數記在變數d，接下來用同樣的方法來尋找b在第幾層，並且把b的層數記在變數e。接下來判斷假設(a的層數在b之上並且b是最後一層，或是，b的層數在a之上並且a是最後一層)，這樣就代表我們不需要移除任何節點，所以return 0，接下來判斷如果(a的層數在b之下或等於b)，則return為a節點以下的所有分支節點，最後其他情況return就為b節點以下的所有分支節點，最後程式跑完function回到main()，在計算總結點數最後減去funtion f的回傳值。
