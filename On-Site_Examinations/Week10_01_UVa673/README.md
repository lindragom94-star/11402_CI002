回到家練習先解決getline(cin,s)會讀到第一行(enter)的錯誤處理，詢問gemini得知有cin.ignore()這個函式，解決第一個問題。將程式碼貼給gemini後，得知有三個地方的錯誤沒有考慮到，(1.)原本(if(s.size()==0))這行寫在(for(int j=0; j<s.size(); j++))裡面，導致if判斷式永遠不會被偵測到。(2.)原本stack跟flag宣告在main()裡的最外面，導致每一輪stack跟flag沒有reset狀態，會發生下一個input被干擾到。(3.)最難發現的問題，如果只輸入'('，程式會進入 if(s[j]=='(') 並執行 c.push('(')，迴圈結束了，因為過程中沒有遇到 else（沒遇到右括號），所以 flag 依然是初始值 true，程式最後判斷 if(flag==true)，輸出 Yes，但正確答案應該是 No，因為括號沒有被閉合。因此最後的判斷式改成if (flag == true && c.empty() == true)來雙重判斷。
