一個雙層迴圈，最外層是跑sandwiches陣列，內層是跑students陣列，把領過sandwich的學生數字設為2，要是學生數字為2就表示領過三明治直接跳過，接下來持續比對三明治是否為學生要的，當跑完內層學生陣列時，檢查flag是否為false，若是，則代表最頂端的三明治沒有人要，所以跳出迴圈，並檢查學生陣列是否還有剩餘不為2的數字，若有，則計算。
一開始int c=0變數定義在class Solution裡、函式int countStudents()外，經由gemini來除錯，得知應該要把c定義在函式int countStudents()內，這樣重複呼叫函式才不會出問題。

一開始flag變數在三明治迴圈內沒有重新將flag設為false，這樣會導致狀況假設students = [1] (愛吃正方形)，sandwiches = [1, 0] (第一塊是正方形，第二塊是圓形)。第一輪 i = 0 (三明治 1)，學生愛吃 1，配對成功。flag 變成 true。第二輪 i = 1 (三明治 0)，學生已經變成 2 了（領過飯了），flag依舊保持上一輪的true，導致下方if(!flag) 判定為 False，所以程式不會break。程式會以為有人領走了這個三明治，繼續跑下一輪。
